How it works

Every element gets one base class. Add modifier classes next to it to change color, size, spacing or shadow. Modifiers combine freely and only affect the element they are on, never the cards or links inside it.

Base classes

Structure

card-1 Top-level card. Cards stack vertically. Title is an <h2>.

card-2 Medium card in a grid inside a card-1. Title is an <h3>.

card-3 Small card inside a card-2. Title is an <h4>.

card-link One link. Goes on an <a>.

Modifiers

Combine freely

Color red rose pink magenta purple indigo blue sky cyan teal green lime yellow amber orange brown gray slate or tint

Fill solid

Size sm lg xl

Grid span wide full (on a card-2)

Margin mt-0 to mt-3, mb-0 to mb-3

Shadow shadow-none shadow-sm shadow shadow-lg

Example markup

<div class="card-2 teal shadow">
  <h3>Reading</h3>
  <div class="card-3">
    <h4>News</h4>
    <a class="card-link" href="https://news.ycombinator.com">Hacker News</a>
    <a class="card-link solid red lg" href="https://lobste.rs">Lobsters</a>
  </div>
</div>

Margins

The hatched stripes show the empty space between cards. Margin classes add to the normal spacing (0.75rem between items inside a card-2). mt is margin-top and mb is margin-bottom. The numbers 0, 1, 2 and 3 mean 0, 0.5, 1 and 2 rem.
